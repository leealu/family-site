# 家庭成长记录网站

这是一个可在 Ubuntu/Docker 上运行的家庭成长记录网站。

## 网站功能简介

- **温馨首页**：展示家庭介绍、欢迎内容和兴趣卡片；家长可编辑网站名称、文案、卡片、页脚，以及主视觉表情或头像。
- **兴趣角**：访客可浏览兴趣卡片及已发布的图片、视频、音频。家长可以上传媒体、编辑卡片，也可以配置兼容的在线音乐音源，搜索并添加歌曲或故事内容供访客播放。
- **成长日记**：家长可记录日期、年龄阶段、标题和成长故事；访客可按日期或年龄阶段浏览，并通过年龄书签跳转。
- **照片与视频相册**：成长记录支持附加多张照片和视频，可翻页浏览并放大查看。
- **家长管理与备份**：家长登录后可管理首页内容、兴趣卡片、成长记录和音乐音源，也可下载或恢复家庭数据备份。
- **自托管与跨设备访问**：网站可通过 Docker Compose 部署；数据库和上传媒体保存在服务器的 `data/` 目录，同一网站地址可供家庭的多台设备访问。

访客无需登录即可浏览已发布的兴趣内容、成长日记及附件。家庭数据和媒体保存在自托管服务器上；请勿将服务器的 `data/` 目录或其中的照片、视频、数据库提交到公开仓库。安装、配置、备份和部署细节见 [`outputs/site/README.md`](outputs/site/README.md)。

## 项目结构

- `outputs/site/`：网站唯一的可维护源码，包括 Python 后端、前端资源和 Docker/安装文件。
- `docs/superpowers/specs/`：经讨论形成的功能设计说明。
- `docs/superpowers/plans/`：经确认后的实施计划。
- `outputs/family-site/` 和 `outputs/family-site.zip`：可重新生成的部署副本，不纳入 Git。

## 本地预览

需要 Python 3.10 或更新版本：

```powershell
cd outputs/site
python server.py
```

浏览器访问 `http://127.0.0.1:8000`。

## Docker 部署

在服务器将 `outputs/site/` 复制到部署目录后，运行：

```sh
docker compose up -d --build
```

部署数据保存在 `data/`，包括家庭数据库和上传媒体。升级源码时不要删除或覆盖服务器上的 `data/`。运行数据、密钥和上传的儿童照片/视频已通过 `.gitignore` 排除；不要将这些内容提交到 Git 仓库。

具体安装和备份方式见 [`outputs/site/README.md`](outputs/site/README.md)。
