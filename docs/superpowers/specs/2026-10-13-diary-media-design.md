# 成长日记照片与视频设计

## 目标

让每条成长记录成为家长登录后可查看和管理的图文/视频日记页。记录仍使用已有的手帐翻页、日期/年龄排序和年龄书签。

## 已确认范围

- 成长记录仅家长登录后可查看、新增、修改和删除；游客接口不返回记录内容。
- 每条记录支持多个图片或视频附件。上传沿用站点现有媒体目录和上传限制（单文件最大 200 MiB）。
- 日记附件随完整备份导出/恢复。家长可在编辑记录时单独移除附件；家长确认删除整条记录时，一并删除该记录附件。
- 现有兴趣卡片公开展示规则保持不变。

## 数据与兼容

- 在 `records` 表增加 `media` JSON 文本列，默认值为空数组；连接数据库时执行向后兼容的列迁移，原有记录因此显示为空附件列表。
- 每项附件只保存受校验的类型、标题、原文件名和 `/media/<随机文件名>` 地址。媒体二进制仍存 `data/media/`，不写进 SQLite。
- 备份格式继续使用现有版本号，记录对象增加可选 `media` 列。恢复旧备份时缺少该列按空数组处理；导入时验证媒体引用与压缩包文件对应，并拒绝目录穿越或不支持的文件类型。

## 接口和权限

- `/api/state` 对游客返回空记录；未登录状态仍返回 `authenticated: false`，不返回家长账号信息。
- 已公开兴趣区引用的媒体仍公开读取；仅由成长记录引用的媒体需要有效家长会话。
- 现有上传、创建、修改和删除接口继续要求有效家长会话。记录创建/更新请求可携带附件数组。
- 只有家长明确保存“移除附件”或确认删除整条记录后，服务端才尝试清理附件文件；先检查兴趣卡片、主页头像及其他日记是否仍引用该文件，仍被引用的文件保留。

## 页面交互

- 记录表单增加图片/视频多选上传、上传状态、附件预览和单项移除操作；修改记录时预载已有附件。取消或上传失败时，未保存附件仍可从表单中的待处理列表明确移除。
- 每页成长笔记展示对应附件；图片自适应，视频使用原生 controls、playsinline 和 metadata 预载。
- 游客不渲染成长记录区；家长登录后看到笔记本、附件和管理操作。
- 保留日期/年龄排序、年龄书签、上一页/下一页和当前的空记录提示。

## 错误处理与边界

- 单文件沿用 200 MiB 上限；只接受站点现有图片和视频格式；失败时给出可见提示，不创建半成品记录。
- 删除确认会明确说明记录附件也将删除；移除单个附件需家长在编辑页操作并保存，不会因普通页面刷新或服务端后台扫描而悄悄删除媒体。
- 日记文字、年龄及仅由日记引用的附件均受家长登录保护。

## 实现涉及文件

- `outputs/family-site/server.py`：迁移、公开读取、记录媒体校验、删除清理、备份/恢复。
- `outputs/family-site/app.js`：表单上传/编辑、访客渲染、每页媒体展示。
- `outputs/family-site/style.css`：手帐页内媒体画廊与移动端布局。
- `outputs/family-site/index.html`：静态资源版本号。
- `outputs/family-site/README.md`：更新公开范围和记录附件说明。
- `outputs/family-site/` 与 `outputs/family-site.zip`：同步可部署的最新包。

## 2026-10-14 已确认的调整

- 成长记录仅家长登录后显示；游客状态的 `/api/state` 不返回日记记录，日记媒体 URL 若不属于公开兴趣内容也要求家长会话。
- 家长会话从登录起固定有效 4 小时，Cookie 与服务端过期时间一致。
- 单条日记中的多媒体改成独立相册翻页，一次展示一个媒体，使用与网站粉彩手帐一致的卡片、圆角、阴影和页码装饰；不改变外层日期/年龄翻页。
- 静态照片在浏览器端缩放到最长边 1920 像素并编码为 WebP（质量约 0.82）；保留动画 GIF，视频不转码。iPhone/Safari 支持的 HEIC/HEIF 照片也走本地 WebP 编码。
- 经 Cloudflare 的大媒体分块上传，单块约 8 MiB，文件总上限继续为 200 MiB；分块暂存于 data 目录，成功合并后移除暂存，下次分块上传时清理超过 24 小时的不完整暂存。
- MOV 上传当前源代码已接受 `.mov`/`video/quicktime`。Cloudflare 不同套餐的代理请求体默认上限可能低于应用 200 MiB 上限，因此分块解决单请求体限制；若实际文件仍失败，具体大小与状态码是后续判断连接超时/源站限制的依据。
