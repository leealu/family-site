# kani的奇妙小世界

这是一个可运行的家庭成长记录小网站。前台是卡通风格主页；后台使用 Python 标准库和 SQLite，无需安装第三方包。支持 Docker Compose，也附有 Ubuntu 一键安装脚本。

## Ubuntu 一键安装

把整个 `site` 文件夹复制到 Ubuntu 服务器后，在该目录运行：

```bash
bash install-ubuntu.sh
```

脚本会检查 Docker 和 Compose 插件；缺少时会先询问，再通过 Docker 官方 Ubuntu 软件源安装。随后构建并启动网站。首次打开页面时创建家长账号。

默认端口为 `8000`。脚本会生成 `.env`；可在启动前修改 `SITE_PORT`。默认使用 HTTP，适用于本机或可信家庭局域网内试用。若需要从互联网访问，请先配置 HTTPS 反向代理，并把 `.env` 中的 `COOKIE_SECURE` 设为 `1`，然后运行 `docker compose up -d`。

成长记录、首页内容和上传的图片/视频/音频保存在当前目录的 `data/` 中（服务器上是 `/opt/family-site/data`），容器重建或升级时会保留。首次部署请运行 `mkdir -p data && chown 10001:10001 data`，并定期备份此目录。

如果旧版本使用 Docker 命名卷 `family-data`，改成 `./data:/app/data` 后旧数据仍留在原卷中；先迁移旧卷数据，再清理任何 Docker 卷。登录后台后也可在“编辑网站”中下载或恢复包含成长日记、页面设置和媒体附件的完整备份。

## 手动 Docker Compose

已安装 Docker Engine 和 Compose 插件时，在本目录运行：

```bash
docker compose up -d --build
```

查看状态：`docker compose ps`。查看日志：`docker compose logs -f`。停止服务并保留记录：`docker compose down`。

## 本地启动

需要 Python 3.10 或更新版本。在本目录打开终端并运行：

```powershell
python server.py
```

然后在浏览器打开 `http://127.0.0.1:8000`。首次使用时创建家长账号，密码至少 12 个字符。数据库会保存在 `data/family.sqlite3`。

## 后台可编辑内容

- 首次访问时创建一个家长账号；此网站按一个家庭账号设计。
- 注册时填写邮箱；之后家长登录只需输入密码。
- 网站名称默认是“kani的奇妙小世界”；可在“编辑网站”→“网站名称和欢迎区”中更改主视觉表情，也可上传静态图片或 GIF。
- 登录后点击右上方“编辑网站”，可修改网站名称、欢迎区文案、介绍卡片、兴趣角标题和卡片、成长日记说明、记录表单提示语及页脚文字。
- 兴趣卡片可新增、修改和删除，最多 8 张；首页基本介绍固定为 3 张卡片。
- 兴趣卡片支持上传图片、视频和音频，每个文件最多 200 MB；兴趣卡片和其中的媒体对网站访客公开显示、播放。
- 可在“编辑网站”→“音乐音源”配置服务器可访问的 Meting API 兼容服务；家长可在兴趣卡片中搜索并添加曲目，访客可在本站播放器播放已添加内容。网易云 HTTPS 分享链接仍作为外链备用；不会抓取或复制平台音频。
- 成长日记、记录文字和附件对网站访客公开；仅家长可在“编辑网站”→“成长日记”新增、修改和删除记录，登录会话从登录时起有效 4 小时。
- 成长日记为翻页记事本，一页显示一条记录，按日期从新到旧排列。
- 游客可以查看兴趣卡片、成长记录和公开附件；仅家长登录后可管理。
- 每条成长记录支持多张照片和视频（JPG、PNG、WebP、GIF、HEIC/HEIF、MP4、WebM、MOV），单个文件最多 200 MiB。静态照片在浏览器中自动缩放并压缩为 WebP；动画 GIF 保留，视频不转码。较大的媒体分块上传，以适配 Cloudflare 代理。
- 成长记录采用可爱手帐翻页样式；每条记录单独一页，可按日期或年龄阶段排序，并可用年龄书签跳到对应阶段；每页的图片和视频在独立相册中翻页；多张时显示叠放相册卡片，点击可自适应放大查看，并用半透明箭头翻页。
- 编辑时可单独移除附件，保存后才生效。确认删除整条记录时，会一并删除不再被其他内容引用的附件。
- 每条成长记录可填写日期、年龄阶段（例如“3岁半”“3岁6个月”）、标题和故事；年龄阶段为选填，旧记录会继续正常显示。
- 记录写入服务器上的 SQLite 数据库。
- 首页内容和成长记录保存在后台数据库，上传媒体保存在 `data/media/`；其他登录设备刷新页面后会看到更新。
- “编辑网站”提供完整备份下载和恢复；备份包含成长记录、日记照片/视频、页面设置和兴趣媒体，恢复保留当前家长账号。
- 页面滚动后右下角会显示回到顶部按钮；编辑窗口关闭按钮会固定在可见位置。
- 登录会话保存在服务端，有效期 4 小时；密码使用 PBKDF2 哈希，不以明文保存。
- 后台编辑文字、图标表情和卡片内容；页面布局、颜色和插画样式暂时由网站设计固定。

### 在线音乐音源

Compose 会同时启动内部的 `meting-api` 服务，容器端口不映射到路由器端口。Meting-API 默认密钥为 `token`；若在 `.env` 中设置自定义 `METING_TOKEN`，后台也要填写相同值。添加音源时，API 地址填写 `http://meting-api/api`，平台代码填写 `netease` 或 `tencent`，鉴权方式选择 `Meting-API HMAC-SHA1`，再点“测试连接”。网站会签名播放请求并读取 302 跳转中的临时地址。之后可在兴趣卡片搜索并添加曲目；浏览器直接从音源加载音频，家庭服务器不转发音频内容。曲目可用性仍由平台授权和限制决定。音源密钥只保存在服务器 SQLite，不会下发给游客或放入网站备份。

## 图片缓存

已发布到兴趣卡片、成长日记或首页头像的图片返回 `Cache-Control: public, max-age=300, s-maxage=300`，允许浏览器和 CDN 缓存 5 分钟。尚未公开的图片仍需家长登录访问，并返回 `private, no-store`。视频、音频、API、登录状态和备份保持原有不缓存策略。

Cloudflare 的 Browser Cache TTL 应设置为尊重源站响应头，Edge Cache TTL 规则也应尊重源站 TTL，避免覆盖 300 秒设置。公开图片删除或取消展示后，已有缓存可能保留至剩余缓存期结束；源站的新请求会立即检查文件和公开引用。若需要立即清除 CDN 副本，可在 Cloudflare 按图片 URL 清除缓存，但浏览器中仍有效的缓存需到期后才重新请求。首次未命中缓存时仍需读取源站，后续命中可减少回源下载。

## 跨设备访问

部署到持续在线的服务器后，同一局域网的设备可以访问 `http://服务器IP:8000`。从互联网访问需要域名或可访问的公网地址、HTTPS 反向代理和防火墙配置。设置 `COOKIE_SECURE=1` 可让登录 Cookie 仅通过 HTTPS 发送。所有设备使用同一个网站地址和家长账号登录，成长记录共用服务器数据库。

上线前请配置 HTTPS 反向代理、限制服务器访问权限，并定期备份 `data/` 文件夹。

## 启动选项

可用 `SITE_PORT` 更改宿主机访问端口；容器内固定使用 8000。Compose 将 `data/` 绑定到 `/app/data`，包括 SQLite 数据库和媒体文件。默认监听所有网络接口以支持同一局域网访问；公网使用应由 HTTPS 反向代理转发到应用端口。

## 微信小程序与学习工作台对接准备

当前网站是第一种客户端。未来的小程序目标是承接整站功能（首页、兴趣相册、成长日记、家长管理、打卡和学习工作台），作为独立客户端使用同一套后端服务与家庭数据，不把网页塞进小程序 WebView，也不让小程序直接读服务器文件或 SQLite。

现在日记、兴趣内容和媒体通过后端 JSON API 读写，网页只负责展示和管理。正式开发小程序前，再将稳定业务接口整理为版本化 API，加入微信登录 code 的服务端兑换、适用于多客户端的令牌/权限机制，并为打卡、学习计划、任务记录等设计独立数据模型。微信 AppSecret 只能保存在服务器端，不能写进网页或小程序包。
